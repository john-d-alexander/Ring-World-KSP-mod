# Installation and your first expedition

Niven Ringworld adds a rotating, landable habitat with procedural terrain, ruins, forests and stock-science exploration. It is an unofficial fan project inspired by Larry Niven's *Ringworld*.

## Install

1. Use KSP **1.12.5, Windows x64 / Direct3D 11**. Close the game before changing mod files.
2. Install **HarmonyKSP / Harmony 2** separately. v1.1.3 requires at least **2.2.1.0**, which is also the tested version.
3. Optionally install **Cyla 1.1.0** for its atmospheric scattering. Without it, Ringworld uses its built-in Original atmosphere.
4. Extract the Ringworld ZIP into your **KSP instance root**, beside `KSP_x64.exe`. The resulting mod directory must be `GameData/NivenRingworld`.
5. Start KSP and open a save. Use a new Sandbox save to learn the flight controls before starting a long expedition.

Keep one copy of each dependency. Do not put the whole ZIP inside `GameData` and create a nested `GameData/GameData` directory. When upgrading from an older bundled release, retain your existing Harmony/Cyla installation unless updating those mods separately.

Download from [GitHub Releases](https://github.com/theplatecrafter/Ring-World-KSP-mod/releases) or [SpaceDock](https://spacedock.info/mod/4573/Niven's%20Ring%20World). See [release notes](../../RELEASE-NOTES.md) for dependency versions and upgrade changes.

## Visit the ring in Sandbox

Build a lander capable of braking and landing in approximately 1 g. Open the ring icon in the stock toolbar, or press **Left Alt+R**. Choose an expedition destination and an arrival height, then use the relocation control.

Relocation matches the ring's tangential velocity and places you above the surface. You still need to control the descent and land. The random terrain control provides additional places to explore. These testing/relocation controls are available in Sandbox; Science and Career retain the information and research features.

Start with **Slow** graphics on a laptop. If movement is sluggish, try a lower preset and reduce KSP's screen resolution. See [graphics settings](QUALITY-PRESETS.md).

## Plan a normal arrival

A velocity-matched approach is essential. The default ring surface moves at hundreds of kilometres per second relative to the central star. Entering its atmosphere without matching that motion is destructive. Crossing the ring's flight boundary does not give your craft free braking.

There is currently no progression-unlocked transport system for bringing a stock craft safely to the surface. Science and Career expeditions need an arrival solution of their own. A practical transport mechanic is planned; the existing Sandbox transfer is a testing aid.
